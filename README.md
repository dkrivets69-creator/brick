# Интерактивный кирпич G-TECH

Секция для страницы кейса: 3D-кирпич со стикерами на Three.js.

- Кирпич медленно вращается. Его можно раскрутить мышью или пальцем в любую сторону.
- Стикер можно потянуть: он отгибается, отрывается и падает за край.
- Подсказки «Крути» и «Отклеивай» нарисованы от руки и анимированы покадрово. Каждая стирается после первого нужного действия.
- Кнопка «Наклеить обратно» возвращает оторванные стикеры.

Фон секции прозрачный, поэтому под ней виден фон страницы сайта.

## Что внутри

| Файл | Что делает |
| --- | --- |
| `index.html` | Сама секция: холст, подсказки, кнопка «Наклеить обратно» |
| `main.js` | Сцена, камера, свет, вращение, пауза вне экрана |
| `brick.js` | Геометрия кирпича: отверстия, сколы, надпись G-TECH |
| `bake.js`, `shaders.js`, `noise.js` | Фактура глины, один раз запекается в текстуру при загрузке |
| `stickers.js` | Стикеры и механика отклеивания |
| `hints.js` | Анимация подсказок |
| `stickers/*.svg` | Картинки стикеров |

## Посмотреть локально

Открыть `index.html` двойным кликом не получится: браузер не загружает JS-модули с диска. Нужен любой локальный сервер. Запустите в этой папке:

```bash
python3 -m http.server 8080
```

Потом откройте http://localhost:8080.

## Разместить на сайте

1. Загрузите папку целиком на любой статический хостинг: GitHub Pages, Netlify (можно просто перетащить папку на app.netlify.com/drop), Vercel или хостинг самого сайта.
2. На странице кейса вставьте секцию через `<iframe>`. Если конструктор сайта позволяет вставлять свой HTML, используйте блок для встраивания кода.

```html
<iframe
  src="https://ВАШ-АДРЕС/brick-section/index.html"
  title="Интерактивный кирпич G-TECH: покрутите и отклейте стикеры"
  loading="lazy"
  style="display:block; width:100%; height:clamp(360px, 56vw, 720px); border:0;"
></iframe>
```

Высоту можно менять: кирпич подстраивается под неё сам. Ширину лучше ставить на всю ширину экрана: тогда оторванные стикеры улетают за край окна, а не за край блока.

## Что можно поменять

- **Стикеры.** Их набор, картинки, грань, положение, угол и размер задаются массивом `STICKERS` в начале `stickers.js`. Чтобы заменить картинку, положите свой SVG в `stickers/`. Если сдвинуть стикер за край грани, он сам загнётся на соседнюю грань.
- **Текст подсказок и форма стрелок** — в `index.html`, внутри `<div id="hints">`.
- **Скорость и дрожание подсказок.** Скорость — в начале `hints.js` (`FPS`, `WRITE_FRAMES`, `ERASE_FRAMES`). Сила дрожания — параметр `scale` у фильтра `#boil` в `index.html`.
- **Скорость вращения** — `BASE_SPEED` в `main.js`.
- **Ракурс** — `POSE`, `START_ANGLE` и `CAMERA_ELEVATION` в `main.js`.
- **Свет** — источники `key`, `rimLeft`, `rimTop` и `fill` в `main.js`.

## Зависимости и производительность

- Three.js 0.180, three-mesh-bvh и three-bvh-csg грузятся с cdn.jsdelivr.net. Шрифты Russo One, Baloo 2 и Caveat — с Google Fonts. Больше ничего устанавливать не нужно.
- Нужен браузер с WebGL 2: это все современные браузеры.
- Кирпич собирается при загрузке примерно за секунду.
- Когда секция прокручена за пределы экрана или вкладка скрыта, рендер ставится на паузу.
- Если кадры идут медленно, чёткость изображения снижается автоматически.
- Если у посетителя включено «уменьшение движения», кирпич крутится медленнее, а подсказки появляются без анимации.
